# 立高官网精修 SPEC（v1 · 2026-10-17）

## 一句话目标

把「内容扎实但呈现业余」的单页站，改成「一眼看到实拍证据、AI 能准确引用」的转化型落地页。**不是推倒重来**——现有的 SEO/JSON-LD/llms.txt 底子要保住。

## 现状诊断（2026-10-17 实测线上站）

| # | 问题 | 证据 | 严重度 |
|---|------|------|--------|
| 1 | 所有 emoji 图标渲染成方框 | 首屏电话 📞、关于区 🏭📋✅🔧、产品卡 15 处 📍 全变 □ | 高（100% 访客可见） |
| 2 | 首屏 8514px 页面，第一屏零实拍 | Hero 只有文字+数字+按钮 | 高（工业门靠实拍建立信任） |
| 3 | 产品图是随手实拍，未剪裁/调色 | 如 rapid-door.jpg 画面含绿植、风扇、墙面杂物 | 中高（图有但不像产品图） |
| 4 | 产品卡信息层级弱 | 图下只有标题+一行描述+项目名+标签 | 中 |
| 5 | 案例区只有图+名称+品类 | 无项目背景、规模、难点 | 中 |

内容底数（不缺）：15 产品全有图 / 12 案例 / 20 份检测报告 / 素材库 355 张实拍 + 93 视频。

## 范围

### P0 硬伤修复（先做，1-2h，低风险）
1. emoji → 内联 SVG 图标（无外部依赖、无线宽、颜色跟随 CSS）
2. Hero 加实拍底图 + 半透明遮罩，保持文字可读（移动端单独压暗）
3. 产品图统一处理：EXIF 纠正、主体剪裁、统一比例、调色偏暖、JPEG q84 progressive
4. 加 `loading="lazy"` 与 `width/height`（防 CLS）

**验收**：桌面/移动截图无方框；首屏在 390px 与 1280px 下文字对比度 ≥ 4.5:1；Lighthouse 性能不降；线上资源全 200。

### P1 证据化（P0 上线后）
5. 产品卡重排：大图 → 型号/规格一行 → 适用场景标签 → 代表项目
6. 案例区补三行：项目背景 / 门型与数量 / 交付难点（只用素材库可核实信息）
7. 客户墙 → 按行业分组，补 logo 或文字标

**验收**：每个新增文案都能在 `~/.ligao` 或现有页面找到出处；抽查 5 条由用户确认。

### P2 AI 可见性（最后）
8. `llms.txt` 扩成结构化速查（产品线/规格/客户/资质/联系）
9. FAQ 可视文案与 FAQPage schema 逐条对齐
10. 补 `Product`/`Service` 结构化数据，`sitemap` lastmod 更新

**验收**：schema 校验通过；FAQ 与页面文案 diff 为空；llms.txt 覆盖 15 产品线。

## 边界（不做）
- 不换域名、不动 robots.txt 的 `Disallow: /images/reports/`
- 不引入框架/构建链，保持单文件 HTML + 内联 CSS
- 不加 JS（汉堡菜单维持 checkbox 方案）
- 不编造客户、项目、参数；无法核实的内容留空而非推测
- 不动报价单脚本等无关文件

## 分工
- **Hermes**：写 SPEC/ACCEPTANCE、选图、验收、上线核验、记录留痕
- **Codex**：按 SPEC 实现 HTML/CSS 与图片处理脚本，不 git commit
- **用户**：定方向、看效果图、拍板取舍（每阶段一次确认）
